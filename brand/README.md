# WheresMyMoney logo: the Dial

The mark is the dashboard's coverage dial: a 270° arc with a fixed 65% fill and a needle. It's a symbol, so the fill never changes to show real data.

| File | Use |
| --- | --- |
| `wmm-mark.svg` | Bare mark on dark UI (top bar at 28px, loading screen) |
| `wmm-mark-light.svg` | Bare mark on light backgrounds |
| `wmm-mark-small.svg` | Bare mark at 32px and below (thicker strokes) |
| `wmm-tile.svg` | Mark on its dark tile, 64px and up |
| `wmm-favicon.svg` | Favicon: tile with thicker strokes |
| `wmm-app-icon.svg` | 512px full-bleed PWA icon; the dial sits inside the 80% maskable safe zone (`"purpose": "any maskable"`) |
| `wmm-logo-dark.svg`, `wmm-logo-light.svg` | Horizontal lockup. The wordmark is live text in IBM Plex Sans SemiBold (600, letter-spacing -0.015em), so in the app render the wordmark as HTML text beside `wmm-mark.svg` instead of using these files |

Colours: teal `#2DD4BF` (arc on dark), deep teal `#0D9488` (arc on light), ink `#E6EDF3` / `#0F1720`, tile `#0D1117`.
Home Screen name: "Money". Clear space: at least the needle's length. Minimum sizes: 16px mark, 120px-wide lockup.
Don't recolour the arc, rotate the mark, change the fill, or retype the wordmark in another font.
Design reference: the Brand page of the design canvas (`BrandLogo.dc.html`).
